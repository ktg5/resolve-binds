# ktg5's resolve keybinds
this repo hosts all of my davinci resolve keybinds


# installation
download this repo by clicking on the green "Code" button & selecting "Download ZIP". extract the `ktg5's Resolve Binds.txt` file and load up a project in resolve. press `Ctrl`+`Alt`+`K` to open the keybinds popup. at the top right of the keybinds popup, click the hamburger button (the 3 dots) & select `Import Preset...`, then select the keybinds file you just extracted & it'll be loaded


# keybinds
## important keys
`Shift`+`1` - Project Manager

`S` - Enable Snapping

`C` - Enable Linking / Locking

`Shift`+`D` - Non-Ripple Delete

`D` - Ripple Delete

`Q`, `W` - Start / End to Playhead

`R` - Change Speed of Selected Clip (opens up speed popup)

`F` - Freeze Selected Clip

`T` - Toggle Selected Clip

`Z` - Zoom to Fit

`X` - Razor (Cut by Playhead)

`Alt`+`1` - Selection Mode

`Alt`+`2` - Trim Edit Mode

`Alt`+`3` - View Window > Transform

`Alt`+`4` - View Window > Fusion

`Alt`+`5` - View Window > OpenFX

`Ctrl`+`Space` - Play in Reverse

## timeline keys 
`Ctrl`+`Shift`+`T` - Create a new Timeline

`Ctrl`+`R` - Render in Place

`Ctrl`+`T` - Open in Timeline

`Shift`+`1`-`6` - Change Clip Color (Violet, Orange, Yellow, Beige, Lime, Olive (in that order))

`Alt`+`R` - Enable "Smart" Render Cache

`Alt`+`Shift`+`R` - Disable Render Cache

## transition keys
`Shift`+`T` - Audio Transition

`Alt`+`T` - Video Transition

## marker keys
`Shift`+`X` - Create Marker

`Shift`+`C` - Create Compound Clip

## grid keys
`Alt`+`G` - Add Line to Grid

`Shift`+`G` - Show Grid
